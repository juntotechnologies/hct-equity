# data

This directory holds the Kaggle competition files. Git ignores everything here except this file.

- Do not commit, copy or share these files. The competition rules forbid redistribution.
- Do not save row-level outputs, for example predictions by ID, outside this directory.
- Get the files with the "Get data" command in the root `AGENTS.md`.
- `test.csv` is a three-row placeholder with no outcomes.
